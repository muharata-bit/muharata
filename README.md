# Muharata Food Company Limited — GitHub Pages Website

A modern, responsive static website for Muharata Food Company Limited's agro-processing machinery business.

## Included
- Muharata-branded logo asset in `assets/muharata-logo.svg`
- The existing Unreal/Unsplash-style photography used in the design
- Responsive navigation and mobile menu
- Product category filters
- WhatsApp enquiry buttons
- Phone and email links
- Back-to-top control
- GitHub Pages compatible HTML/CSS/JS
- No bio-fertilizer/fertiliser section or references

## GitHub Pages
1. Upload all files to the repository root.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save and open the generated Pages URL.
