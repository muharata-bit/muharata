# Muharata Food Company Limited — GitHub Pages package

This package is a static GitHub Pages website for Muharata Food Company Limited.

## Included
- Home, About, Machinery, Services, History and Quote sections
- Machinery/tool catalogue with category filtering
- Responsive mobile navigation
- Quote/enquiry form that opens WhatsApp
- Phone: **0785 756 215**
- Facebook: https://www.facebook.com/profile.php?id=61575150263838
- No Bio-Fertilizer section or Bio-Fertilizer navigation

## Deploy
Upload the contents of this folder to the `muharata` GitHub repository and enable GitHub Pages from the repository's Pages settings.

The site uses no build process or framework: `index.html` + `assets/style.css` + `assets/app.js` are sufficient.
