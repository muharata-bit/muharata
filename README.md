# Muharata Modern GitHub Pages Website

A modern, responsive single-page website for Muharata Food Company Limited.

## Included
- `index.html` — complete page structure and content
- `style.css` — responsive design, animations, layout and components
- `script.js` — mobile menu, machinery filters, active navigation and back-to-top button

## Deploy on GitHub Pages

1. Create a new GitHub repository, for example `muharata-website`.
2. Upload `index.html`, `style.css` and `script.js` to the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save. GitHub will provide the live Pages address.

## Before publishing
Replace the demo/stock image URLs in `style.css` with your own machinery photographs for a stronger, more authentic website.

Update any phone, email, address, social media links or product specifications if the official details change.
